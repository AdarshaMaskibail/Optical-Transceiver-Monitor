# Optical-Transceiver-Monitor
A portfolio project connecting Embedded C with optical-network equipment concepts.
The program simulates an optical transceiver controller that monitors Tx/Rx power, temperature, laser bias and supply voltage, then generates alarms and exposes a simple command interface.
